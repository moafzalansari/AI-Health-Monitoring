# HealthNova AI - AI Module

This module will handle the intelligent analysis of health data.

## Main Responsibilities

- Health data preprocessing
- Personal baseline generation
- Anomaly detection
- Risk scoring
- Explainable AI

## Input Data

- Heart Rate
- SpO2
- Temperature
- Activity
- HRV (if available)

## Planned Approach

Sensor data will be processed and analyzed against the user's
personal baseline to identify unusual health patterns.

The system is designed for health monitoring and early risk
detection, not medical diagnosis.
